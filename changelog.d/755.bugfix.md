Fixed the dashboard showing a pane as plain "Idle" while it still had a delegated task outstanding (issue #755). When an orchestrator delegates a task to a worker pane and hasn't yet received a matching `work-done` report, the worker's card now shows a distinct "(delegated)" badge and border color instead of an indistinguishable "Idle" — so an orchestrator watching the dashboard can tell "genuinely idle, never given work" apart from "still working, or finished but hasn't reported yet." The idle completion bell and the tab bar's aggregate "N idle" count were updated the same way, so all three surfaces now agree with each other instead of the badge alone changing while the bell still rings and the count still includes the pane.

This is populated from the daemon's own delegation-tracking state (`worker-agent-deck daemon status`'s `outstanding_delegation`/`silence_watch`/`delegation_commission` fields), which already existed but was previously discarded by the dashboard's rendering path entirely. The indicator is refreshed at hydration, at reconnect, and now also live: the daemon pushes the change to every already-attached dashboard the instant a delegation is armed or retired, so a pane you are watching continuously updates its badge/bell/count without needing to disconnect and reconnect first.
