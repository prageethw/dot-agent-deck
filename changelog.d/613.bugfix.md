Fixes a stale-pointer defect in `dot-agent-deck delegate`: the daemon's worker-task pointer sentence (`Read .dot-agent-deck/worker-task-<role>.md for your task.`) was relative, so a worker whose process cwd had drifted from the daemon's `pane_cwd_map` belief about its pane could silently resolve the pointer against the wrong directory and read an unrelated, pre-existing file instead of erroring — this produced three real reviewer/auditor reports on an already-merged, unrelated PRD before being traced to its root cause. The pointer is now an absolute path, built from the same `file_path` the daemon actually wrote. The task-file name is also now keyed on the target pane's id as well as its role (`worker-task-<role>-<pane digest>.md`), mirroring `work_done_file_name`'s existing pane-keying on the report leg (upstream #331 + fork #76) — two panes running the same role in the same directory no longer collide on the same task file.

Pinned by four `src/state.rs` unit tests: `resolve_delegate_task_body_pointer_survives_a_worker_cwd_mismatch` reproduces the drifted-cwd scenario against a planted decoy file and confirms the real task is read instead; `delegate_task_file_name_is_keyed_by_pane_not_role_alone` and `resolve_delegate_task_body_two_panes_same_role_same_cwd_do_not_collide` pin the pane-keyed filename; and the pre-existing `resolve_delegate_task_body_points_at_the_file_it_wrote` / `_inlines_when_the_file_cannot_be_written` / `_inlines_when_no_cwd_is_recorded` were updated to assert the pointer is absolute (or, on the fallback paths, that no pointer sentence is emitted at all, whatever its format).

No-Test: the pins above are plain `#[test]` unit tests against `resolve_delegate_task_body`/`delegate_task_file_name` directly, not `#[spec]`-annotated catalog tests — the change is an internal daemon invariant (the format of a coordination-file pointer/filename), not TUI-observable behavior a `#[spec]` test could pin. A handful of existing `#[spec]` e2e tests do assert the old relative-pointer/role-only-filename literal (e.g. `tests/orchestration_delegate.rs`, `tests/delegate_prompt_injection.rs`, `tests/e2e_dispatcher_mode.rs`) and are left unmigrated in this round — deferred and listed in this PR's report, since the mechanical migration is real but separate churn from this fix.
