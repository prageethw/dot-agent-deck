## A pi-native worker that exits before replying no longer leaves the orchestrator reading `Observing`

A `delegate` with `clear = true` to a pi-native worker returned before recording the replacement worker's agent id on the delegation. If that replacement exited before sending `work-done`, the daemon could not match the exit to the delegation, so the worker's card read `Idle (delegated)` and the orchestrator's read `Observing` until `worker_response_timeout_minutes` ran out. The agent id is now recorded on the pi-native path as it already was on every other path, so the delegation is retired when the worker exits and both cards return to `Idle` straight away.
