Fixes `dot-agent-deck wrap`'s Codex integration never reporting the active model to the daemon — `Emitter::build_event` hardcoded `model: None` on every emitted event unconditionally, so PR #651's badge fix had no model to actually surface for a wrapped Codex session. The wrapper now reads the model back out of Codex's own interactive status bar (`gpt-5.1-codex-mini low · <cwd>`), anchored on the specific ANSI span that paints it rather than a bare substring scan, and reports it sticky on whatever event goes out next.
