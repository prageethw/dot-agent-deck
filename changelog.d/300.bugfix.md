Fixes `worker-agent-deck worktree list --mine` refusing outright for a human caller at an interactive terminal, who has no reason to export `DOT_AGENT_DECK_WORKTREE_OWNER`. An absent env var now falls back to the same human-identity resolution unmarked worktree rows already use (`gh api user`), only refusing once both the env var and that resolution have failed. `is_mine`'s `owned` conjunct, which could never be true for an unmarked human-owned row, now also accepts a matching human-owner row on identity alone, so a resolved human identity can actually match its own worktrees.
