Every dashboard card now shows its number badge, not only the first nine. Previously the badge silently stopped past card position 9, with no fallback — the tenth card onward rendered with no number at all. The `1`-`9` Normal-mode digit-jump shortcut (`Action::FocusCard`) is unchanged and still only reaches cards 1-9; only the always-visible display badge was decoupled from that single-digit limit.
