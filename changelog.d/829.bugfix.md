## Worker panes share their column evenly, with any leftover rows going to the first panes

When several panes share a column, the deck now divides its height directly: every pane gets the same number of rows and any leftover rows go one each to the first panes. Before, the division was rounded at each pane boundary, so the shorter and taller panes could sit anywhere in the column, for example a middle pane a row taller than its neighbours.
