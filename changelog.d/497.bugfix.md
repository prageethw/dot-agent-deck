Fixes the bottom bar's two `status_message` render call sites (`render_bottom_bar`'s `UiMode::PaneInput` arm and its `_` fallback arm) passing status-message text straight to `Line::styled` with no sanitization, letting a `Cf` bidi-format character such as `U+0600` (ARABIC NUMBER SIGN) — not filtered by ratatui's own structural stripping — reach the rendered terminal buffer. Both call sites now run the message through `strip_control_and_bidi` before rendering. `ui.status_message` is a single private field with one writer pattern and exactly these two readers that render it; sanitizing both closes the exposure completely, so #497 is fully addressed by this fix.
