Fixed several follow-up issues in `.claude/skills/dot-ai-tag-release/cleanup.sh` (the release skill's worktree/branch cleanup detection, Step 6) found in a post-merge review of the previous fix. A second, linked worktree on the default branch could be offered for deletion — `git worktree remove` succeeds on it, unlike the root checkout, so this was worse than the original bug. The main working tree's own path could silently resolve to the wrong location instead of degrading.
