## A delegation that never reaches the worker no longer leaves the orchestrator reading `Observing`

When a `delegate` was accepted but the task never reached the worker — the `clear = true` respawn failed, the replacement worker never became live, or the identity gate refused the task pointer — the daemon released the delegation's commission but left its outstanding-delegation record armed. The worker's card read `Idle (delegated)` and the orchestrator's read `Observing` for up to `worker_response_timeout_minutes` (2 hours by default), followed by a "worker silent" notice, for a task nobody had been given. The record is now retired on each of those exits, so both cards return to `Idle` straight away and no notice is sent.
