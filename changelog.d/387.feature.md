## `Ctrl+L` Reaches Your Agent Again, and the Split Is Now One Setting for the Whole Deck

`Ctrl+L` is clear-screen for shells, readline, and every agent you run in a pane — Claude Code included. In an Orchestration tab the deck claimed it regardless of what you were doing, so a focused role pane's agent never saw the keystroke and its own clear-screen simply never worked. Running an interactive agent in a role pane is what the deck is for, which made that the worst possible place to swallow the chord. It now passes straight through to the pane's occupant as `^L` (byte `0x0c`) whenever you are typing in a pane, on every tab type. Dashboard tabs already behaved this way.

**This costs one keystroke if you had the habit.** To cycle the split from an Orchestration tab while a pane is focused, press `Ctrl+D` first to reach command mode, then `Ctrl+L`. That is a deliberate trade, and the same one `Ctrl+W` (close pane) already makes: a chord the program inside your pane genuinely needs is scoped to command mode rather than eaten forever, so you pay one extra keystroke in the rarer direction instead of losing the chord in the common one.

**The split stage is also no longer per tab.** It used to be one stage per tab, so cycling one tab left the others where they were. There is now a single stage shared by the Dashboard and every Orchestration tab: cycling anywhere moves everywhere, and a tab you open afterwards starts at whatever stage is current. Sidebar width reflects how you like to read, not which tab you happened to open — but if you were deliberately keeping one tab wide and another narrow, that combination is no longer possible.

Nothing else about the cycle changes. The three stages are still Default → Narrow (25/75) → Hidden (sidebar gone, pane column full-width) → Default, `Default` still resolves to each tab type's own ratio (33/67 on the Dashboard, 34/66 in an Orchestration tab), and the stage still resets to Default on the next launch rather than persisting. Mode tabs have no sidebar split and never claim the chord.

Like every other keybinding, `toggle_orchestration_split` is remappable through `[global]` in `~/.config/dot-agent-deck/keybindings.toml`; whatever chord you bind it to is command-mode only. See [Keyboard Shortcuts](https://agent-deck.devopstoolkit.ai/docs/keyboard-shortcuts) for the full list.
