## CI: the `desktop-browser` job no longer hangs for 20 minutes on a floating pnpm version or a slow package mirror

The job was cancelled at its 20-minute timeout on about one run in seven, from two separate causes. On 29 September a run of pnpm 12.6.0 left the job silent after all 112 tests had passed, because the workflow asked for "pnpm 12" and took whatever 12.x was latest; the pnpm version is now pinned exactly in both desktop jobs. On 30 September and 1 October the Ubuntu package mirror served WebKit's 125 MB of system packages at about 118 kB/s and the install step alone used the whole budget; that step now has its own time limit and a bounded retry, and the Playwright run has test and global timeouts, so a stall fails in minutes with the step named and its report kept instead of ending as an unexplained cancel.
