Fixes `worker-agent-deck`'s `Dir:` line rendering a Unicode bidi override (e.g. `U+202E` RIGHT-TO-LEFT OVERRIDE) sent through a session's `cwd`. Following the same pattern PR #662 applied to `display_name`/`tool_name`/`tool_detail` for issue #562, `event.cwd` is now sanitized at the `apply_event` ingest choke point before it is stored on `session.cwd`, the rename-path `is_valid_cwd` gate now rejects Unicode format characters (mirroring `is_valid_display_name`, closing the gap between its doc comment's claim and its actual behavior), and the daemon-echo hydration scrub (`sanitize_record_tab_membership`) now scrubs `AgentRecord.cwd` as well, closing a gap where that field was previously left completely unscrubbed on that path.
