Fixes three more fixture-git-invocation helpers that PR #663 (issue #579) missed neutralizing git's location-discovery environment variables in: `xtask/linkage-check/src/work_type.rs`'s `git()` helper (used by `--self-test`'s scratch repos), `xtask/linkage-check/tests/resurrected_changelog_fragment.rs`'s copy of the same helper, and `tests/release_cleanup.rs`'s `run_git()` (used by the `cleanup.sh` fixture suite). Each previously neutralized only `GIT_CONFIG_GLOBAL`/`GIT_CONFIG_SYSTEM` (the first two) or `GIT_DIR`/`GIT_WORK_TREE` (the third), leaving `GIT_COMMON_DIR`, `GIT_INDEX_FILE`, `GIT_OBJECT_DIRECTORY`, `GIT_ALTERNATE_OBJECT_DIRECTORIES`, `GIT_CEILING_DIRECTORIES`, and `GIT_NAMESPACE` ambient — the same read/write escape shape #579 fixed in `repo_state.rs`'s `Sandbox::git()`, reachable from the same pre-commit-hook/`git rebase --exec`/`git bisect run` contexts. The first two helpers now `env_remove` all 8 location vars (a plain removal is correct for both, since every fixture command they run always targets an already-initialized repo or an init/clone target, never a walk that could resolve past `cwd` into nothing). `run_git()` in `tests/release_cleanup.rs` `env_remove`s the other 5 straightforward vars alongside its existing `GIT_DIR`/`GIT_WORK_TREE` clearing, but binds `GIT_CEILING_DIRECTORIES` to the target directory itself (canonicalized, falling back to the uncanonicalized path) rather than clearing it — mirroring the same file's own `run_cleanup` precedent, which already bounds the script-under-test's ceiling at the OS temp dir for the same reason: a directory that is not itself a repository must fail discovery closed at that directory instead of silently resolving a real repository somewhere above it.

No-Test: the regression is pinned by `git_test_helper_leaks_ambient_git_dir_and_git_work_tree` in both `xtask/linkage-check/src/work_type.rs` and `xtask/linkage-check/tests/resurrected_changelog_fragment.rs`, and by `release_cleanup_028_run_git_leaks_ambient_git_index_file`/`release_cleanup_029_run_git_does_not_bound_upward_discovery_with_git_ceiling_directories` in `tests/release_cleanup.rs` — real tests (RED before this fix, GREEN after), not a documentation gap.
