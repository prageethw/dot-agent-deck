## After a session restore, focus lands on the start role's pane instead of an arbitrary one

Restoring an orchestration tab from a snapshot focuses a pane so you can type straight away. The deck ordered its panes by sorting their ids as numbers, but pane ids are now minted as `pane-<hex>-<n>`, so no id parsed as a number and the order came out arbitrary, different on every run. The pane that got focus could be any role's instead of the start role's. The deck now keeps panes in the order they were created, and a restore focuses the start role's pane explicitly. The saved-session file and the dashboard's card order still use the old sort; that is tracked separately.
