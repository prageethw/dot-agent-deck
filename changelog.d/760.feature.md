The New Pane form's orchestration branch gets its "Worktree slug" field back: an optional, short, human-typed identifier that names the isolated-clone workspace directory and branch, separate from the descriptive orchestration "Name" you type. Tab from Name to reach it once an orchestration is selected.

Leave it blank and nothing changes for you: a fresh open auto-generates `orchestrator-N`, exactly the pre-existing behavior. Type one (e.g. `fix-544`) and it — not the potentially long, descriptive Name — becomes the workspace's folder/branch name, while Name keeps doing its own job: the tab title and the uniqueness check that stops two orchestrations from colliding.

Reopening under the identical slug resumes the same on-disk workspace rather than creating a new one, the same persistent/resumable behavior every isolated-clone workspace already has.
