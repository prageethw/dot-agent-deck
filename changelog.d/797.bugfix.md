Codex worker panes no longer read `Working` constantly (issue #797, regression since v0.50.0). The two-phase process sampler now also reads the command line of a pane root and its direct children whenever the pane has a detached descendant, so the `wrap` primary-child exemption can recognise `worker-agent-deck wrap` and stop treating the idle `node codex` child as a detached background command. Issue #797 stays open until verified in a release.
