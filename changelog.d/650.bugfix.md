Fixes the agent-type badge (`Ctrl+m` / `m`) on a resolved-but-untagged session (real activity seen, but the pane never picked up a concrete agent type) either hiding a known model entirely or, once gated on activity instead of the raw placeholder flag, showing a misleading `No agent (<model>)` next to a live status. Such a session now shows its model alone in the badge (e.g. `gpt-5.2-codex`) when one is known, and shows no badge at all when none is known yet; a genuinely-empty, never-resolved placeholder is unaffected.
