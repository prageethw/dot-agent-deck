## The default log file moved off a predictable /tmp path

When `DOT_AGENT_DECK_LOG` was left empty or set to `1`, the deck wrote its default debug log to the fixed path `/tmp/dot-agent-deck.log` — a predictable filename in a world-writable directory, opened with no protection against a symlink pre-planted there before first use (CWE-59/377).

The default now resolves under the per-user state directory instead (`~/.local/state/dot-agent-deck/deck.log` on Linux, `%LOCALAPPDATA%\dot-agent-deck\deck.log` on Windows), created owner-only (mode `0700`) the same way the daemon's own `daemon.log` already is. This closes the cross-user attack the issue reported. An explicit `DOT_AGENT_DECK_LOG=<path>` still writes exactly where you point it, unchanged.
