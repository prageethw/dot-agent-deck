Picking an agent from the New Agent form's `Agent:` chip (used to declare identity for a mode-pane launcher command that isn't auto-inferable, e.g. a bespoke Codex wrapper script) is no longer silently discarded once the pane spawns. The form's explicit selection now drives the mode-pane wrap decision alongside the mode's own `agent = "…"` declaration, so a launcher the user explicitly told the deck was Codex is wrapped through the Wrapper strategy (`dot-agent-deck wrap --agent codex --`) and reported as Codex on the Dashboard card, instead of running bare with the card stuck on "No agent" (issue #640).
