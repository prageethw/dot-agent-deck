- **A pane_id reused for a worker role no longer keeps a stale orchestrator flag**

  `register_orchestration_role` only ever *inserted* into `orchestrator_pane_ids` when a pane was registered with a start role, with no corresponding removal when the same pane_id was later reused for a plain worker role. That left the pane wrongly flagged as an orchestrator, and `delegate_targets`'s orchestrator-exclusion filter then silently dropped it as a legitimate delegate candidate.

  Reusing a pane_id for a non-start role now clears the stale flag, so the pane is correctly eligible as a delegate target again.
