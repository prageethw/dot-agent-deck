## A delivery to a pane named with no target identity or session generation is now refused, instead of possibly being misdelivered

A write-and-submit to a paned target that named no expected agent id, or no expected session generation on an attached pane, could previously be delivered anyway — keyed by pane id alone, with no confirmation of who or which session actually received it. Both axes now fail closed: a caller that supplies no target identity is refused before any write is attempted, and an attached pane with no named session generation is refused at delivery time, matching the behavior already documented (but not previously enforced) for that case.
