- **One work-type vocabulary — `bug | prd | doc | chore` — reconciles what used to be five disagreeing surfaces**

  This repo had five places carrying work-type vocabulary: `pyproject.toml`'s changelog types, `scripts/assemble-changelog.sh`'s own list, `.claude/skills/dot-ai-tag-release/analyze.sh`'s stricter list, GitHub labels, and the `prds/` directory's unused `PRD`-label convention. Three of them disagreed, and two were already hard gates capable of blocking a release. `assemble-changelog.sh` now reads its valid type list from `pyproject.toml` instead of hardcoding a separate one, closing a latent release-blocker where a fragment suffix accepted by one gate could be rejected by the other.

  The vocabulary, its rationale, and the conflicts it resolves are documented at `docs/develop/work-types.md` (see [`https://github.com/prageethw/dot-agent-deck/blob/main/docs/develop/work-types.md`](https://github.com/prageethw/dot-agent-deck/blob/main/docs/develop/work-types.md) — this page is a developer reference and is not published to [the docs site](https://agent-deck.devopstoolkit.ai/docs/)).
