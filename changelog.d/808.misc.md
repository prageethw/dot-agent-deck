## CI: the `semgrep` check no longer fails on two deliberate bidirectional-character test fixtures

`desktop/src/components/EndpointsPanel.test.tsx` and `desktop/e2e/decks.spec.ts` embed U+202E on purpose, to prove the desktop strips it from a remote deck's label. Semgrep's `contains-bidirectional-characters` rule flagged them as blocking findings on every run, so the check was red on every PR. The two files are now listed in `.semgrepignore`; the rule itself stays active for the rest of the tree.
