Fixes an interactive `codex` pane getting stuck showing "Thinking" forever: the wrapper's Codex line classifier only knew how to resolve back to `Idle` from JSON (`codex exec --json`) output, so the interactive TUI's plain-text redraw lines could drive the card to `Working` but never back down, even once the session had gone quiet. The non-JSON fallback now recognizes the interactive TUI's own "waiting for input" style prompts as a real idle signal.
