Fixes an interactive `codex` pane getting stuck showing "Thinking" forever, and a related false "Idle" reading mid-turn. Guessing turn state from the interactive TUI's raw redraw text turned out to be unreliable in both directions — a repaint batch carrying only the composer's idle placeholder (with no co-resident spinner text) could still read `Idle` mid-turn, and a turn's closing footer could carry no marker at all and leave the card wedged at `Working` once the session went quiet. For a session where Codex's own native hooks are confirmed installed and trusted (the common/default case), the wrapper now defers entirely to those hooks — the same `UserPromptSubmit`/`Stop` signals that already drive every other agent's card — instead of guessing from text, so the card only ever changes on a real turn boundary. Text-based classification remains as a best-effort fallback for the narrower case where hook trust could not be confirmed; that fallback can still exhibit the residual mid-turn/end-of-turn flicker described above, a known and accepted limitation of the no-hooks path (tracked in #640).
