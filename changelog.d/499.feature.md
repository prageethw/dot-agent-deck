## Monitored external waits now show as active work, not idle

`worker-agent-deck wait start <label>` declares a monitored external wait for the calling pane, and `worker-agent-deck wait done <label> --outcome <success|failure|cancelled|timeout>` clears it — so a role that is polling an external dependency (CI, another delegated worker, an approval) in discrete steps, or whose own delegated task has already reported done but is still responsible for noticing an outcome, reads `Working` for the whole span rather than `Idle`. A wait that is never explicitly cleared self-heals after a TTL (`DOT_AGENT_DECK_WAIT_TTL_SECS`, 30 minutes by default, capped daemon-side at 6 hours) rather than wedging the pane `Working` forever.

The promotion composes correctly with the existing shell-activity signal (a pane is `Working` if either signal is active) and reaches an attached or reconnecting dashboard, not just the daemon's own internal state.
