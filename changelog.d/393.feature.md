The command-entry lock that keeps your typing on the orchestrator pane is now a command-mode chord, one value for the whole deck, and out of the way of an agent that has stopped to ask you something.

**`Ctrl+e` now only toggles the lock from command mode, so unlocking is `Ctrl+d` then `Ctrl+e`.** If you have the habit of pressing `Ctrl+e` straight from a focused pane, that is the one thing to relearn here. The reason is the same one `Ctrl+w` and `Ctrl+l` already gave up a keystroke for: `Ctrl+e` is end-of-line in shells, readline and every agent you run in a pane, and the deck was eating it before the pane ever saw it. Now it reaches whatever you are typing into, and the status message on a blocked keystroke names both chords.

**One lock, not one per tab.** Toggling it on any orchestration tab changes every other open orchestration tab too, and a tab you open afterwards adopts the current value instead of starting locked. Previously each tab kept its own, so unlocking had to be repeated in every tab with nothing on screen to say why. Dashboard and workspace-mode tabs are still never locked, and the lock still only applies to orchestration tabs — only where the setting lives changed.

**A pane that is waiting for input is no longer locked.** When an agent stops and asks — a permission prompt, a numbered list, a yes/no, a free-text question — you can answer it in that pane without unlocking anything, and the lock re-engages as soon as the status clears. The lock exists to interrupt the reflex of typing at an agent that is working; answering one that explicitly asked you a question is not that.

**The 30-second inactivity snap-back is gone.** Focus used to return to the orchestrator after 30 seconds of leaving a role pane alone. It no longer does, and there is no timer of any kind. Focus now moves on its own only while the deck is locked, and only on a status change you can see coming: it steers to a role pane that starts waiting for input, and returns to the orchestrator once nothing on the tab still needs you. While unlocked, nothing moves focus at all — it stays where you put it until you lock again.
