## `ListAgents` Reports Registration Generation and Daemon Boot ID

`worker-agent-deck`'s `ListAgents` query now reports each agent's current `pane_registration_generation` and the daemon's `daemon_boot_id` alongside the existing fields. Both were previously visible only to the spawned pane's own process environment (`DOT_AGENT_DECK_REGISTRATION_GENERATION` / `DOT_AGENT_DECK_DAEMON_BOOT_ID`), which meant an out-of-process caller that needed to construct a `work-done` signal for a specific pane had no way to discover the values a real spawn would have injected. This is additive and backward-compatible — no `PROTOCOL_VERSION` bump required.
