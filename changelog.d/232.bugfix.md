## A crafted directory name could rewrite what `worktree list` showed you

worker-agent-deck printed worktree paths, and git's own error output, straight to the terminal. A directory name containing terminal control characters — an ESC sequence, a carriage return, a bidirectional-text override — is acted on by the terminal rather than displayed, so a crafted name could overwrite or reorder the lines around it: hiding a worktree from the listing, or making a row appear to say something it did not. That matters most in `worktree reclaim`, where the listing is what you read to decide which worktrees to delete.

Every terminal output path in `worktree list` and `worktree reclaim` now rewrites control and bidi characters to a visible escaped spelling before printing, including the raw error text git produces when enumeration itself fails. The escaping is injective, so two directory names that differ still render differently rather than collapsing into the same display string. `--json` output is deliberately left raw, since it is consumed by programs rather than by a terminal.
