Fixes `xtask/linkage-check/src/work_type.rs`'s `resolve_base` — the read-path sibling issue #669 didn't touch — silently trusting whatever repository an ambient `GIT_DIR`/`GIT_WORK_TREE` (left behind by, e.g., a `pre-commit` hook or a `git rebase --exec` parent) pointed at instead of the `repo_dir` it was explicitly given, because its `git merge-base HEAD <base>` invocation only set `current_dir` and cleared no environment at all.
