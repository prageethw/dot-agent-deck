## Tests: `restore_008` and `idle_worker_008` no longer fail intermittently

`restore_008_daemon_empty_snapshot_rebuilds_orchestration_tab` located a role's card by text that also matched the focused pane's header, so whenever the rebuild happened to focus `reviewer` it read the header's row instead of the card's; it now reads each role's row off the card itself, through a shared locator that recognises a card by the number badge in its title and that a fast-tier test guards. `idle_worker_008_closed_orchestrator_pane_id_reuse_receives_nothing` reused a pane id as soon as `StopAgent` answered, which is one step before the daemon releases the pane for reuse, and so could fail with `Duplicate pane id`; it now waits for the daemon to report the close finished. That repair is upstream's (vfarcic/dot-agent-deck PR 1224), taken as is ahead of the next sync. No product behaviour changes.
