## Watch panes now start when worker-agent-deck is installed at a path containing a space

A watch pane runs by building a shell command line that contains worker-agent-deck's own executable path followed by the command to watch. Neither operand was shell-quoted: the executable went in bare, so an install path such as `/opt/My Deck/worker-agent-deck` split into two words and the pane never started, and the command went through Rust's debug formatting, which looks like quoting but is not a shell-quoting contract — a command containing `$`, backticks or a real newline was still mangled or re-interpreted.

On Unix both operands are now POSIX single-quoted, verified by round-tripping values through a real shell and comparing the recovered bytes rather than by inspecting the generated string.

On Windows no quoting is applied, deliberately. `cmd.exe` has no equivalent single-quote construct, and a correct implementation has to be position-aware: the escaping needed to contain an embedded quote in the command breaks ordinary executable paths such as `C:\Program Files (x86)\...`. Windows behaviour is therefore byte-for-byte identical to previous releases — which remains inadequate for a watched command containing shell metacharacters, and is tracked separately as issue #283.
