The wait-observing indicator — a `Working` status currently held up by a monitored external wait (`worker-agent-deck wait start`) rather than real agent activity — now renders as the bare word `Observing` instead of `Working (observing)`, on both the `worker-agent-deck daemon status` human table and the TUI deck card's status label. The shell-busy `*` marker, when it also applies, still attaches directly to the status word (`Observing*`), unchanged in composition from before. The `--json` document's `wait_observing` field and the card's `STATUS_OBSERVING` border colour are unaffected — this is a text-only change to the human-facing label.
