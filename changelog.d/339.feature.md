- **A command-mode toggle shows the agent-type badge on session cards**

  `Ctrl+M` (or a bare `m`, which always works on tmux and other legacy terminals where `Ctrl+M` decodes as `Enter`) shows a coloured `ClaudeCode` / `OpenCode` / `Codex` / `Pi` badge on every session card's title, restoring the badge fork-only commit `370b6228` removed. It is one setting for the whole deck — toggling it on any tab changes every card everywhere, including a pane opened afterwards — off by default and not persisted across restarts.

  The toggle is command-mode only: `Ctrl+M` is the CR byte that submits input to every supported agent, so claiming it while typing in a pane would have silently stolen that keystroke. See [Keyboard Shortcuts](../docs/keyboard-shortcuts.md#ctrlm--m-shows-the-agent-type-badge) for the full behaviour.
