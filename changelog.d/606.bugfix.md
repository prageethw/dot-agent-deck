`.github/workflows/e2e.yml`'s `cargo nextest run` invocation now carries `--workspace`, matching `.cargo/config.toml`'s `test-e2e` alias in package and feature selection. Without it the job selected the root package alone, so a test gated behind the `e2e` feature in any `xtask/*` workspace member would have been silently skipped in the one CI job that runs that tier.

No-Test: CI workflow configuration only — the diff changes which packages `cargo nextest` selects in one GitHub Actions job and touches no production code path, so there is no TUI-observable behaviour a `#[spec]` catalog test could pin. The flag's effect is verified directly by the job's own summary line, measured A/B on this change: 11050 tests bare vs 11311 with `--workspace` (726.9s vs 696.8s wall).
